# Gizlilik Politikası / Privacy Policy

**Son Güncelleme / Last Updated:** 31 Ekim 2026

## Türkçe

### 1. Genel Bilgilendirme
**Arşiv Açıcı** ("Uygulama"), kullanıcı gizliliğine azami önem vermektedir. Bu gizlilik politikası, uygulamanın kullanıcı verilerini nasıl işlediğini açıklamaktadır.

### 2. Toplanan Veriler
Arşiv Açıcı, tamamen **çevrimdışı (offline)** çalışan yerel bir Windows masaüstü uygulamasıdır:
- Uygulama hiçbir kişisel veri, dosya içeriği, telemetri veya analitik verisi **toplamaz**.
- Açtığınız veya sıkıştırdığınız dosyalar yalnızca yerel bilgisayarınızda işlenir; hiçbir sunucuya veya üçüncü tarafa gönderilmez.
- İnternet bağlantısı gerektirmez ve arka planda ağ trafiği oluşturmaz.

### 3. İzinler
Uygulama yalnızca kullanıcının seçtiği arşiv dosyalarını okumak ve belirtilen hedef klasöre çıkarmak veya yeni arşiv oluşturmak için yerel dosya sistemi erişimini kullanır.

### 4. İletişim
Gizlilik politikası ile ilgili sorularınız için GitHub üzerinden iletişime geçebilirsiniz:
https://github.com/omerbek/Archive-Opener/issues

## English

### 1. Overview
**Archive Opener** ("the Application") is committed to protecting your privacy. This Privacy Policy outlines how the Application handles user data.

### 2. Data Collection
Archive Opener is a completely **offline**, local Windows desktop application:
- The Application does **not** collect, store, or transmit any personal data, file contents, telemetry, or analytics.
- All file extraction, compression, and browsing operations occur entirely on your local machine; no data is ever uploaded to external servers.
- The Application does not require an active internet connection and generates zero background network traffic.

### 3. File System Access
The Application only accesses files and folders explicitly selected by the user for the sole purpose of extracting or creating archives.

For any questions regarding this Privacy Policy, please reach out via GitHub:
